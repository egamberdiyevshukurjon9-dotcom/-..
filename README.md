# «Яшил белбоғ» — экологик мониторинг платформаси

Экологияни яхшилаш учун: Ўзбекистон ҳудудлари бўйича яшил қоплама, тупроқ, ҳаво сифати ва дрон мониторинги.

Платформа — битта `index.html` ва кичик `server.js` (Node.js 18+, кутубхонасиз):

```bash
node server.js       # http://localhost:5174
```

Серверга ўрнатиш бўйича қадамма-қадам йўриқнома — [DEPLOY.md](DEPLOY.md).

**Жонли маълумот:** об-ҳаво, PM2.5, PM10 ва минерал чанг интернетдан — [Open-Meteo](https://open-meteo.com)'дан (бепул, калитсиз) олинади ва ҳар 10 дақиқада янгиланади. Дарахтлар, лойиҳалар, тупроқ ва дронлар бўйича рақамлар ҳозирча демо.

## Бўлимлар
- **Бошқарув панели** — ҳудуд кўрсаткичлари, харита, об-ҳаво, рейтинг, вилоятларни солиштириш, «Кўнгилли бўлиш» аризаси
- **Эко-харита**, **Ҳаво сифати** (PM2.5/PM10, AQI), **Дрон мониторинги**, **Таҳлил**, **Илмий база**
- **Админ панель** — лойиҳалар, ходимлар, кўнгиллилар аризалари (CSV), роллар, чатбот созламалари, API уланиши
- **Ёрдамчи бот** — офлайн билимлар базаси ва платформа маълумотлари бўйича жавоб беради
- Экспорт: PDF (чоп), CSV, JSON, HTML · Тиллар: ўзбек (кирилл/лотин), рус, инглиз · ёруғ/тунги мавзу

> Лойиҳалар, ходимлар ва аризалар ҳозирча браузерда (localStorage) сақланади.
> Ҳақиқий тизимда кириш ва рухсатлар сервер томонида текширилиши шарт.
